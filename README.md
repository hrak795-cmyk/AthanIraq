# أذان العراق — Athan Iraq

مشروع Android أصلي باستخدام Kotlin وJetpack Compose، الحد الأدنى Android 8.0 (API 26) وTarget SDK 34.

## البناء
1. فك ضغط الملف وافتح مجلد `AthanIraq` باستخدام Android Studio حديث.
2. ثبّت JDK 17، ثم انتظر Gradle Sync.
3. أنشئ APK من `Build > Build Bundle(s) / APK(s) > Build APK(s)`.

## ما يتضمنه المشروع
- واجهات الصلاة والقبلة والأدعية والسبحة والتقويم.
- تخزين إعدادات وعدّاد السبحة والمفضلات باستخدام DataStore.
- Aladhan API method=7، مع إزاحة المغرب الافتراضية +12 دقيقة والعشاء بعد المغرب بـ15 دقيقة.
- مستشعر Rotation Vector لحساب اتجاه القبلة، وحساب المسافة إلى مكة.
- تنبيه محلي عبر AlarmManager، قناة إشعارات وأذونات مطلوبة.
- موارد لغات عربية وصينية مبسطة وروسية وإنجليزية افتراضية.

## ملاحظات مهمة قبل النشر
- **الأدعية:** ملف `assets/duas.json` يحتوي مقتطفات قصيرة فقط وليس النصوص الكاملة لدعاء كميل والتوسل والفرج؛ أضف نصوصًا كاملة موثقة قبل النشر.
- **دقة أوقات الصلاة:** بيانات Aladhan طريقة 7 أساس أولي. توقيت المغرب الشرعي في العراق قد يختلف حسب المدينة والمرجع؛ تحقق من مصدر محلي موثوق. لا تعتبر +12 دقيقة فتوى موحدة لكل الحالات.
- **تنبيهات الأذان:** يجب جدولة كل صلاة بعد جلب الموقع والأوقات، وإعادة الجدولة بعد إعادة تشغيل الجهاز. مستقبل الإقلاع في هذا الإصدار هيكل تمهيدي فقط، ولا يشغل صوت أذان كاملًا. كما يلزم طلب إذن الإشعارات على Android 13+ وإذن المنبهات الدقيقة حسب نسخة النظام.
- **اللغات:** ملفات strings جاهزة كبداية، لكن النصوص داخل بعض الشاشات مكتوبة مباشرة بالعربية؛ يلزم نقلها إلى موارد strings وتطبيق تغيير اللغة فعليًا لإكمال التدويل.
- **GPS:** الإصدار يستخدم آخر موقع معروف؛ أعد المحاولة إذا لم يتوفر، ويمكن تحسينه بطلب تحديث موقع جديد.
- **الاختبار:** هذا مشروع مصدر جاهز للفتح في Android Studio، لكن لم يُجرَ بناء Gradle أو اختبار على جهاز في بيئة الإنشاء هذه. راجع أي تحذيرات/أخطاء بعد المزامنة قبل الاعتماد الإنتاجي.
